# L5-P1｜十字段最小预测方案

> 依据：`L5_TARGET_ANALYSIS.md` 实统计。  
> 本轮只定方案，**不开始训练**。  
> 原则：标签类型来自数据集；不引入赛题外管理体系；简单有效优先。

---

## E. 每字段推荐预测方法

| 字段 | 标签形态 | 最小方案 | 是否复用 L2–L4 | 备注 |
|---|---|---|---|---|
| 1 设备状态 | 4 类有序 | **多分类**（CatBoost/RF）；可选有序损失 | **优先复用 L2** 已有状态输出（仅限已覆盖设备）；其余设备 L5 自训 | 非法类无；评估加邻级误差 |
| 2 故障类型 | ≤5 类 | **多分类**；按设备掩码未出现类 | **优先复用 L2** 故障类型 | 除鳞泵仅 3 类等 |
| 3 故障严重度 | 有序 1–5 | **有序/多分类**（先多分类基线） | 不直接当 L2 输出 | 报告 MAE/邻级准确率 |
| 4 故障位置 | 24 类、设备相关 | **分设备多分类**或共享骨干+设备条件头 | 不复用 L2（L2 未必输出位置） | `-` = 正常占位 |
| 5 诊断置信度 | 连续 0.62–0.99 | **回归**（RF/CatBoost Regressor），输出 clip 到 [0,1] | 不把 L3 置信当特征（防泄漏） | 与状态弱解耦 |
| 6 频谱描述 | 9 模板 | **模板 ID 分类** → 映射原文 | 可用 L3 频谱叙述作**报告对照**，不作训练特征（v1） | 禁止开放生成主路径 |
| 7 根因分析 | 39 模板 | **模板 ID 分类** | L4 根因作报告对照；v1 不做特征 | 精确匹配为主 |
| 8 建议措施 | 20 模板 | **模板 ID 分类** | 同上 | 同上 |
| 9 优先级 | P0–P3 | **多分类/有序** | 可由状态强相关作级联，但 v1 建议**独立头**防误差放大 | 类别以数据集为准 |
| 10 影响程度 | 14 模板 | **模板 ID 分类** | 不自造高中低 | 保留标点变体为不同类 |

**不做：** 每字段独立 Agent；默认深度序列模型；赛题外 P 等级重定义。

**级联策略（可选第二版）：**  
`状态/故障类型 → 严重度/优先级 → 位置 → 文本模板`。  
第一版并行多头更稳，便于泄漏隔离与消融。

## F. 输入特征与标签隔离

### F.1 允许的推理输入（v1）

1. 数据集观测列（19 维物理/频谱量）  
2. `设备类别`（或映射后的 `equipment_type`）作条件特征  
3. 确认无泄漏的派生量（如简单比值），须在文档登记  

### F.2 禁止的推理输入

- 十字段 10 答案字段及任何直接派生  
- `labels.csv` / `diagnostic_output` / 含答案的 PED 标签列  
- `记录编号`、行号、文件名、sheet 内序（仅追溯）  
- 用**同一验证记录答案**训练出来的 L2/L3/L4 分数当特征（未做防泄漏重训前）

### F.3 上游输出策略

| 用途 | v1 |
|---|---|
| L5 模型特征 | **不使用** L2–L4 输出 |
| 最终报告展示 | L2–L4 作为**独立分析栏**与 L5 预测并列 |
| 状态/故障类型 | 若某设备已有 L2：报告可展示 L2；L5 仍自训对照；融合留到证明无泄漏后 |

### F.4 训练时监督

仅训练集答案列作 y；特征矩阵 X 与 y 物理隔离（列白名单）。

## G. 训练/验证划分方案

### G.1 主方案（必做）

对每个设备表：

1. 按 `采集时间` 升序。  
2. 前 **80%** → train，后 **20%** → valid。  
3. 同一 `设备编号|采集时间` 的多记录整组归同一侧。  
4. 六类分别划分后合并评估（同时报 per-equipment 与 micro/macro）。

### G.2 禁止作为唯一依据

- 全局随机划分（时间泄漏）。  
- 直接用官方“测试集”冒充独立测试（与训练同观测）。

### G.3 成绩报告三通道命名

| 名称 | 数据 | 允许用途 |
|---|---|---|
| `fit_repro` | 在训练观测上预测（含可见训练标签的拟合） | 自检管道，不写“泛化” |
| `internal_val` | 时间留出验证 | **主指标** |
| `blind_test` | 独立带标签集 | **当前无**；有新数据前不填写 |

## H. 评价指标

| 字段 | 主指标 | 辅指标 |
|---|---|---|
| 设备状态、故障类型、故障位置、频谱/根因/措施/影响、优先级 | accuracy、**macro-F1** | 混淆矩阵；位置/文本加 per-class support |
| 故障严重度、优先级（有序） | macro-F1 + **邻级准确率**（\|pred−true\|≤1） | 严重度另报 MAE（级别差） |
| 诊断置信度 | **MAE**、RMSE | 分设备 MAE；可选相关 |
| 模板文本三类 | **精确匹配率** | 归一化编辑距离/相似度仅辅助；**不等于**根因物理正确 |

汇总：先报六类设备各自 `internal_val`，再报全体 macro 平均。

```
  data_split.py         # 时间划分与组约束

  models_tabular.py     # CatBoost/RF 多头
  metrics.py
  report_predict.py     # 写出十字段预测表
```

### 实施顺序（待下一阶段）

1. **数据管道**：划分 + 泄漏断言（测试不得读到答案；X 不含目标）。  
2. **头 A**：设备状态、故障类型（对齐 L2 标签空间）。  
3. **头 B**：故障严重度、优先级。  
4. **头 C**：故障位置（分设备）。  
5. **头 D**：诊断置信度回归。  
6. **头 E**：频谱/根因/措施/影响 → 模板分类。  
7. **拼装**：输出与数据集同名的十字段；与 L5a 报告槽位对齐。  
8. **对照**：有 L2 的设备做状态/类型一致性表（不自动覆盖，除非协议规定）。

依赖：表格学习库（CatBoost 或 sklearn RF）；**不**阻塞于 LLM。

## J. 可靠预期与明显限制

### 相对可做、预期较稳

- 设备状态、故障类型、严重度、优先级（有限类 + 强结构相关）  
- 诊断置信度回归（连续、无缺失）  
- 模板类文本（唯一值少，适合闭集分类）

### 明显限制

1. **无独立带标签测试** → 不能声称真实泛化。  
2. 位置与文本模板 **设备绑定** → 全局模型易混类。  
3. 状态↔优先级/严重度相关高 → 级联会放大误差；需消融。  
4. 置信度与状态解耦弱信号 → 回归上限可能有限。  
5. L2 仅覆盖部分设备类型 → 无法六类都“只复用不训练”。  
6. 模板精确匹配 ≠ 现场根因正确；赛题内以数据集字符串为准。

### 与现有 L5a/L5b 关系

- L5a：报告容器与证据；本方案填充**数据集十字段预测值**。  
- L5b：规程参考告警；**不**替代十字段，也不引入额外审批字段到预测目标。
