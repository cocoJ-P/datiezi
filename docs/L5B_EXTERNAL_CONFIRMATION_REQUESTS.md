# L5B｜外部确认问题清单

> 性质：协作问卷，非正式批准。  
> 只列仓库无法用 A 级证据闭合的缺口；已确认项不重复索要。  
> 回填后建议更新位置见各题「回填落点」。

---

## A. 数据提供方 / 采集系统负责人

### A1. X/Y 振动统计量

| 项 | 内容 |
|---|---|
| 需要回答什么 | `X向振动(mm/s)` / `Y向振动(mm/s)` 是 RMS、peak、peak-to-peak、瞬时值还是其它？是否速度？ |
| 为什么需要 | KB-03 与全部 X/Y 振动规则目前 `statistic=unresolved`；L5b 禁止猜测 RMS |
| 对应规则 | KB03-MM-VIB-XY-*、KB03-GB-VIB-*、KB03-CWP-VIB-*、YAML-MM-VIB-*、YAML-DP-VIB-X/Y-*（共 9 条） |
| 未回答阻断 | 振动正式比较与正式告警；仅能 indeterminate |
| 可接受材料 | 采集规范、DCS/在线监测点表、厂商配置导出、带版本号的特征计算说明 |
| 回填落点 | L1 Schema/采集元数据；`semantics.py` 登记；规则 `statistic`；必要时新 catalog 版本 |

### A2. 「振动均方根」定义

| 项 | 内容 |
|---|---|
| 需要回答什么 | 计算窗口、滤波、是否速度 RMS、单位如何得到；与 X/Y 列关系；是否允许由轴合成 |
| 为什么需要 | 列名像 RMS（B），L1 `requires_review`，PED `unit: null`，存在 `rms_from_axes` 开发桥 |
| 对应规则 | 当前目录无专用 RMS 阈值；但影响是否将来用 RMS 对拍 KB |
| 未回答阻断 | 任何基于 RMS 的正式规则启用 |
| 可接受材料 | 特征工程说明书；禁止仅凭列名 |
| 回填落点 | L1 `vibration_rms`；取消或确认 bridge；feature contract |

### A3. 「最大振动」定义

| 项 | 内容 |
|---|---|
| 需要回答什么 | max 的时间窗/通道聚合方式；是否与 X/Y 同一传感器 |
| 为什么需要 | 与分量/RMS 不得默认等价；`YAML-DP-VIB-MAX-ALARM` 来源未核实 |
| 对应规则 | YAML-DP-VIB-MAX-ALARM |
| 未回答阻断 | 最大振动正式告警 |
| 可接受材料 | 点表 + 算法说明 |
| 回填落点 | semantics / 规则 measurement_kind |

### A4. 传感器与采样

| 项 | 内容 |
|---|---|
| 需要回答什么 | 振动/温度传感器型号；安装方向与位置；采样率或记录周期；特征生成链路 |
| 为什么需要 | 仓库无传感器文档与采样日志（C） |
| 对应规则 | 全部 19 条（测点/工况适用性） |
| 未回答阻断 | `measurement_location` / 工况核验无法从 `from_feature_name_only` 升级 |
| 可接受材料 | 测点图、仪器清单、采样配置导出 |
| 回填落点 | 设备配置 / PED metadata；适用性校验扩展（未来，非本轮改代码） |

### A5. 单位与换算

| 项 | 内容 |
|---|---|
| 需要回答什么 | 表内 mm/s、°C、g 是否已是最终工程单位；有无现场换算 |
| 为什么需要 | P3/P4 可做映射，但无证明源列已换算完成 |
| 对应规则 | 全部带 unit 的规则 |
| 未回答阻断 | 单位争议时 applicability unresolved |
| 可接受材料 | 单位制说明或标定记录 |
| 回填落点 | P3 映射确认状态 |

### A6. 齿轮箱油温字段

| 项 | 内容 |
|---|---|
| 需要回答什么 | 油温在哪一列/哪一系统；为何开发集六表均无油温列 |
| 为什么需要 | `KB03-GB-OIL-TEMP-*` 特征在现表无法观测 |
| 对应规则 | KB03-GB-OIL-TEMP-ALARM/DANGER |
| 未回答阻断 | 齿轮箱油温任何评估 |
| 可接受材料 | 数据字典增补或其它测点表 |
| 回填落点 | 数据集列；L1 Schema；L2 gearbox features |

## B. 设备工程师

### B1. 六类设备型号与部件

| 项 | 内容 |
|---|---|
| 需要回答什么 | 各 `设备编号` 对应型号；电机/泵/齿轮箱/风机/连铸驱动的部件边界 |
| 为什么需要 | KB-03 含功率/结构描述，但未与现场台账绑定 |
| 对应规则 | 全部 KB03-*；风机/连铸尚无规则 |
| 未回答阻断 | 型号限定与 `operating_conditions` 核实 |
| 可接受材料 | 设备台账、铭牌照片、PID/布置图 |
| 回填落点 | equipment 主数据；规则 equipment_id 范围 |

### B2. 测点位置

| 项 | 内容 |
|---|---|
| 需要回答什么 | DE/NDE、X/Y 的物理安装点是否与规程测点一致 |
| 为什么需要 | 温度冲突裁决与振动适用性依赖“同一测点”证明 |
| 对应规则 | 全部轴承温度与振动规则 |
| 未回答阻断 | 测点适用性无法从列名升级为 A |
| 可接受材料 | 测点布置图、规程附图对照 |
| 回填落点 | 适用性元数据 |

### B3. 额定与典型工况

| 项 | 内容 |
|---|---|
| 需要回答什么 | 额定转速/负载；规程适用的运行区间；记录是否在适用工况内 |
| 为什么需要 | 规则 `operating_conditions` 目前无法对运行时核验 |
| 对应规则 | 全部 |
| 未回答阻断 | 工况门控；易误用限值 |
| 可接受材料 | 操作规程适用条款 + 运行记录抽样说明 |
| 回填落点 | 规则 operating_conditions；未来工况校验 |

### B4. 无 L2 管道设备的分析准备

| 项 | 内容 |
|---|---|
| 需要回答什么 | 齿轮箱、冷却泵、助燃风机、连铸是否纳入下一阶段 PED/L2 |
| 为什么需要 | 仅有 Excel 表不足以声称告警能力 |
| 对应规则 | KB03-GB-*、KB03-CWP-*；（风机/连铸无规则） |
| 未回答阻断 | `blocked_by_applicability` 无法解除 |
| 可接受材料 | 上线计划与特征契约确认 |
| 回填落点 | `backend/l2/equipment/config/*`（未来） |

## C. 规程负责人 / 运营方

### C1. 正式规程版本

| 项 | 内容 |
|---|---|
| 需要回答什么 | 是否以仓库内 KB-03 docx 为现行有效版本？有无更新版？ |
| 为什么需要 | 目录抽取依赖该文本；版本未运营背书 |
| 对应规则 | 全部 KB03-* |
| 未回答阻断 | `source_status` 无法升为“运营确认” |
| 可接受材料 | 受控文件清单、生效日期、签字页 |
| 回填落点 | KnowledgeSnapshot / 规则 source 元数据；批准日志 |

### C2. 电机 75°C / 85°C 裁决

| 项 | 内容 |
|---|---|
| 需要回答什么 | 报警与危险的正式定义；YAML 将 85 标为 alarm 是否作废 |
| 为什么需要 | 四条温度规则 `blocked_by_conflict`；系统不得自动择优 |
| 对应规则 | KB03-MM-BEARING-TEMP-*、YAML-MM-BEARING-TEMP-*-AS-ALARM |
| 未回答阻断 | 电机轴承温度正式告警 |
| 可接受材料 | 书面裁决 + 废止/保留 YAML 的决定 |
| 回填落点 | 冲突关闭记录；新 catalog 版本；**人工**批准后写 `approvals_v1` |

### C3. 高压除鳞泵专用限值

| 项 | 内容 |
|---|---|
| 需要回答什么 | 除鳞泵振动/温度正式限值及文件；可否采用现 YAML 4.5/7.1/80 |
| 为什么需要 | KB-03 无除鳞章；YAML 来源 `pump-*-guideline-internal` 未核实 |
| 对应规则 | YAML-DP-*（4 条） |
| 未回答阻断 | 除鳞泵正式告警；`blocked_by_source` / measurement |
| 可接受材料 | 泵专用规程或经批准的厂内标准 |
| 回填落点 | 新规则 source_document；废止“冷却泵迁移”任何暗示 |

### C4. 批准权限与审计

| 项 | 内容 |
|---|---|
| 需要回答什么 | 谁有权批准 AlertRule；批准要哪些字段（人、时间、版本、依据） |
| 为什么需要 | 生产 `approvals=[]`；禁止仅前端写 approved |
| 对应规则 | 未来所有拟 `approved_active` 的规则 |
| 未回答阻断 | **任何**正式安全告警 |
| 可接受材料 | 权责文件；首批批准样例 |
| 回填落点 | `approvals_v1.json`（仅人工流程写入） |

### C5. 风机与连铸

| 项 | 内容 |
|---|---|
| 需要回答什么 | 是否有正式阈值规程；是否纳入 L5b 范围 |
| 为什么需要 | 有数据表、无 KB 专章、无 AlertRule |
| 对应规则 | 无 |
| 未回答阻断 | 该类设备正式/参考规程告警均未建立 |
| 可接受材料 | 规程或“本阶段不纳入”的书面范围 |
| 回填落点 | 范围声明；若纳入则新规则目录版本 |

6. **C5** 风机/连铸范围决策。
