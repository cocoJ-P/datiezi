## F. 六类设备对照（要点）

- 故障类型 / 频谱：多数设备 val≈1.0（数据可分性极强）。  
- **故障位置**：齿轮箱/电机/冷却泵 val accuracy≈0.53–0.64，macro-F1 更低 → 多类长尾。  
- **根因分析**：电机/齿轮箱 train→val 跌幅约 0.23–0.25 → 明显过拟合。  
- 助燃风机 / 连铸 / 除鳞泵：模板类字段整体更高、更稳。

6. **L2 四级状态差异？** 已处理：L5 独立训练四类；文档声明 ≠ L2 二分类。

8. **是否需改选型？** 基线保留；位置/根因建议 P3 前增强，**不**改回 LLM 主路径。  
9. **是否满足 L5-P2 工程验收？** **是**（训练/划分/泄漏防护/评测/推理/契约齐全）。
