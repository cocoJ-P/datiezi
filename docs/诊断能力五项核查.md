# 诊断能力五项核查

核查日期：2026-11-06  
核查对象：当前仓库已实现的诊断链路，以及本机已放入的发榜资料派生库。

数字分两条线，不能混用：

| 线 | 是什么 | 能回答的问题 |
|---|---|---|
| L5P-v1 监督预测 | 模型 `L5P-f037a960e2e1`，六类设备按时间后 20% 留出（`internal_val`，共 4797 条） | 故障类型、设备状态、优先级、影响程度、建议措施、根因模板与数据集标注的一致程度 |
| L3/L4 证据与根因推理 | 信号证据、知识检索、图谱查询、程序化校验 | 推理是否接上信号/知识/图谱，有没有规则校验；**没有**对照专家的 Top-3 命中率 |

官方测试集与训练观测重合，`blind_test` 通道不可用。下面的正确率都是时间留出，不是独立盲测。L4 根因确认状态固定为 `unconfirmed`，交付说明写明：无专家金标准，不报告根因准确率。

## 1. 四类典型故障识别

类别为数据集「故障类型」：轴承磨损、转子不平衡、齿轮异常、润滑故障，另有「正常」。不是每类设备都有全部四类：高压除鳞泵只有正常 / 转子不平衡 / 轴承磨损；加热炉助燃风机没有齿轮异常；连铸扇形段驱动电机没有转子不平衡。

**故障类型判定正确率：99.46%**（4771 / 4797）。六设备宏平均准确率 0.995，macro-F1 0.993。只统计真实标签属于四类故障的样本：判对 **99.09%**（2397 / 2419）。

| 真实类型 | 判对 / 样本 | 召回 |
|---|---|---|
| 轴承磨损 | 911 / 913 | 99.78% |
| 转子不平衡 | 627 / 634 | 98.90% |
| 齿轮异常 | 383 / 385 | 99.48% |
| 润滑故障 | 476 / 487 | 97.74% |

主轧机电机、齿轮箱、冷却泵、高压除鳞泵四个头在留出集上准确率为 100%。误差在加热炉助燃风机（97.86%）和连铸扇形段驱动电机（98.87%），主要是转子不平衡与润滑故障互混。

**正常时段误报率：0.17%**（4 / 2378）。真实标签为「正常」却被判成故障的 4 条，全部被判成润滑故障。正常类召回 99.83%，精确率 99.58%。

**给出置信度：是。** 十字段有独立字段「诊断置信度」，输出裁剪到 \[0, 1\]。时间留出平均绝对误差 **0.036**（六设备微平均 0.0358）。它是数据集置信度标签的回归值，**不是**故障类型判对的概率。故障类型头只返回类别名，不返回各类概率。界面写明这一语义。

## 2. 根因诊断推理

**Top-3 命中率：没有这项评测。**  
L4 不把根因排成 Top-3 去对专家金标准。可靠性收尾写明「无专家金标准，不报告根因准确率」，确认态保持 `unconfirmed`。

能对照数据集标注的，是 L5「根因分析」模板的整句精确匹配，不是 Top-3：

| 指标 | 时间留出 |
|---|---|
| 微平均准确率 | **85.03%**（4080 / 4797） |
| 六设备宏平均准确率 | 0.851 |
| macro-F1 | 0.699 |

最弱设备是主轧机电机。错误主要是相似模板重叠、同一故障不同部件表述不同。L5 模板与 L4 未确认根因并列，模板命中不等于物理根因已确认。样例 `REC-MA-20260314-00008` 的根因对照结论是证据不足，不是已确认。

**是否结合信号分析、知识检索与图谱关联：推理运行时会。** 默认报告路径可以只出 L5 预测，不自动再打检索或大模型。

| 层 | 只读工具 | 作用 |
|---|---|---|
| L3 Reasoning | `get_l3_evidence` | 已保存的观测、支持/反对证据、缺失条件 |
| L3 Reasoning | `search_fault_knowledge` | Hybrid RAG（BM25 + 向量 + RRF） |
| L3 Reasoning | `query_equipment_graph` | 部件、故障特征、规程参数 |
| L3 Reasoning | `get_related_cases` | 相似专家案例 |
| L4 Reasoning | `get_l3_evidence`、`get_causal_knowledge`、`get_fault_knowledge` | 信号证据与因果条目 |
| L4 Reasoning | `get_equipment_dependencies`、`inspect_causal_path` | 设备关联与因果路径 |

L4 Core 另有 8 条策展机理（轴承接触疲劳、润滑油膜、转子质量不均、齿轮啮合等），每条带来源文档与所需观测，状态是候选机理，不是已证实因果。图谱关系本身不表示当前故障已经发生。

**推理过程有规则校验：有。** 非法引用不能标成成功。

- L3：校验证据 ID、假设来源和证据角色。只有通用异常、没有故障特异证据时，不得标为支持；轴承类反对证据过窄时，不得整类否定。
- L4：候选 ID、证据 ID、因果知识 ID 必须落在本次允许集合内；确认态必须保持未确认；影响程度必须为空；禁止写成“已经传播到下游”。伪造 `fake*` / `FORGED*` 引用会被拒绝。校验失败记为 `validation_failed`，不当作推理成功。

## 3. 风险等级与处置优先级

系统**没有**名为「风险等级」的独立字段，也**没有**另组专家的盲评一致率。L5a 交付写明：无正式风险等级、无独立专家一致率。下面的一致率，是时间留出预测与**数据集标注**的一致程度。

| 数据集字段 | 业务上对应 | 微平均一致率 | 宏平均准确率 | macro-F1 |
|---|---|---|---|---|
| 设备状态（正常 / 预警 / 报警 / 危险） | 最接近风险等级的四级状态 | **99.25%** | 0.992 | 0.950 |
| 故障严重度（1–5） | 严重程度 | 93.02% | 0.930 | 0.805 |
| 优先级（P0–P3） | 处置优先级 | **89.87%** | 0.899 | 0.762 |

优先级的宏平均 F1 明显低于准确率，类别不均衡，少数紧急等级更弱。

**同时给出影响范围与处置建议：监督十字段会同时给出。**

| 字段 | 微平均精确匹配 | 宏平均准确率 | macro-F1 |
|---|---|---|---|
| 影响程度 | **97.10%** | 0.971 | 0.928 |
| 建议措施 | **96.98%** | 0.970 | 0.909 |

这两项是训练区模板还原，不是现场工单。L4 只给出潜在影响拓扑，`propagation_status=unknown`，不输出影响等级。L5a 另有「验证建议」，类型是待人工复核的核查项，明确不是维修或停机指令。

## 4. 每条结论的证据与前端追溯

**不是每条诊断结论都同时带上信号证据和知识依据。**

有 L3 分析时，支持证据和反对证据写成「特征名 = 观测值」，并带计算说明和 `evidence_id`。这是信号证据。知识依据要另做知识增强或根因推理才会挂上：条目含 `knowledge_id`、类型、适用性、内容摘要、来源文档和行定位。未增强时界面写「尚未对该记录做知识增强」。没有 L3/L4 Run 时，L5 仍可只凭 19 维观测给出十字段，知识区显示未运行，不编造依据。

报告追溯（`FinalEvidenceProvenance`）按字段返回：字段值、来源层与 Run、证据项（特征名、观测值、判定）、知识 ID、模型输入指纹、数据包与知识快照版本。知识条目在这条追溯里给 ID 和「详见 L4 因果知识目录」，不把原文整段复制进报告。

**业务人员可以在前端沿真实 Run 往回看，深度止于证据项和知识摘要，不是每一格都能点开原始 Word 段落。**

| 位置 | 能看到什么 |
|---|---|
| 诊断总览 | 带真实 `diagnosis_run_id` / 记录，进入 L4、L5 |
| L3 工作台 | 已观测标量、支持/反对证据的特征与数值、知识检索摘要与文档定位、推理轨迹 |
| L4 工作台 | 候选、支持/反对/表现证据 ID、因果知识 ID、路径；确认态保持未确认 |
| 报告中心 | 十字段十项；每个字段可「查看证据追溯」，展开为追溯 JSON |

L3 工作台列表默认只展开前 12 条证据，其余在持久化 Trace 里。报告中心的追溯是技术详情里的 JSON，不是逐步向导。

## 直接回答

1. 四类故障类型判定正确率 **99.46%**（只看四类故障样本 **99.09%**）。正常时段误报率 **0.17%**。给出诊断置信度，时间留出 MAE **0.036**，不是分类概率。
2. **没有**根因 Top-3 命中率。根因模板整句匹配 **85.03%**，且不升格为已确认根因。推理运行时会调用信号证据、知识检索和图谱；输出有程序化规则校验。
3. 没有独立风险等级和独立专家盲评。相对数据集标注：设备状态一致率 **99.25%**，维修优先级 **89.87%**。影响程度与建议措施会同时给出，精确匹配约 **97.1%** 和 **97.0%**。
4. **不是**每条结论都同时具备信号证据和知识依据。有分析 Run 时，前端可以从结论追到特征观测值和知识条目摘要、文档行定位；报告追溯给证据 ID 与知识 ID，不展开全部原文。
5. 六份发榜文档全部进入检索库。图谱吃进约 **45%** 的正文行。有设备、部件、故障、特征、案例、处置和参数的关联，**没有**原因节点，处置也不连到故障。支持按故障检索相似案例。
